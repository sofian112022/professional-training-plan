# professional-training-plan
خطة تدريب احترافية شاملة وفقاً لمعايير جهاز الدولة المصرية - Professional Training Plan according to GAHR Standards

## قانون العمل ١٤ لسنة ٢٠٢٥

ملف `قانون-العمل-14-لسنة-2025.xlsx` كتاب تشغيلي للقانون: بحث برقم المادة وباسمها معًا، وبكلمة أو كلمتين تظهر نتائجها قبل النص، ثم نص المادة الرسمي وتحته شرح تطبيقها. ورقة «أرقام التشغيل» تجمع المدد والنسب في صفحة واحدة.

يُعاد توليده بالأمر `python3 tools/build_workbook.py`.
